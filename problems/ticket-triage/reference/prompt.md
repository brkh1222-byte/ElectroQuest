Classify the customer support ticket into exactly one label.

Labels:
- bug: something is broken, crashes, errors, or behaves incorrectly
- billing: anything about payments, charges, invoices, refunds, or plans. If a ticket mentions money, choose billing.
- feature: a request for new functionality

Examples:
Ticket: The page freezes when I scroll. -> bug
Ticket: Please add keyboard shortcuts. -> feature
Ticket: The app froze and I was billed twice. -> billing

Reply with only the label, in lowercase, with no other words.
