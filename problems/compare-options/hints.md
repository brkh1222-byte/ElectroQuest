A checklist instead of an opinion, then the decision in a fixed place:

> The message lists needs and some options. Exactly one option meets every need. Check each option against each need, one at a time, and write pass or fail for each. "At most" and "at least" include the number; "under" and "less than" do not. Then, on the very last line, write only the letter of the option that meets every need, like B. Write nothing after it.
